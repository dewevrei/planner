# SKALA 학습 플래너

HTML, CSS, JavaScript로 구현한 학습 목표 관리 웹 애플리케이션입니다.

## 1. 구현한 기능 목록

| 번호 | 기능 | 주요 내용 |
| --- | --- | --- |
| F1 | 목표 추가 | 빈값과 공백 입력을 검사하고 오류 메시지 표시 |
| F2 | 완료·삭제 | 목록의 이벤트 위임으로 완료 상태 변경 및 목표 삭제 |
| F3 | 필터·진행률 | 전체·진행중·완료 필터와 완료 비율 표시 |
| F4 | 데이터 저장 | localStorage를 이용해 새로고침 후에도 목표 유지 |
| F5 | 마감일 | 날짜 입력 및 마감일이 지난 목표 강조 |
| F6 | 검색 | 목표 제목을 기준으로 실시간 검색 |
| F7 | 분류별 요약 | HTML·CSS·JS별 남은 목표 개수 표시 |
| F8 | 정렬 | 마감일 임박순과 최신순 정렬 |
| F9 | 목표 수정 | 제목을 더블클릭해 수정하고 저장 |
| F10 | 다크모드 | CSS 변수를 활용한 라이트·다크 테마 전환 |
| F11 | 우선순위 | 높음·보통·낮음 설정, 배지 표시 및 우선순위순 정렬 |

## 2. 실행 방법

VS Code의 Live Server를 사용해 http://localhost:5500/ 접속합니다.

## 3. 어려웠던 점과 해결

| 어려웠던 점 | 해결 방법 |
| --- | --- |
| 동적으로 생성된 목표의 이벤트 관리 | 목표 목록에 하나의 이벤트 리스너를 등록하고 이벤트 위임 적용 |
| 검색·필터·정렬 후 화면과 데이터 상태 유지 | goals 배열을 기준으로 화면을 다시 렌더링하고 변경 시 localStorage에 저장 |
| 마감일과 우선순위 정렬 기준 처리 | 날짜 문자열과 우선순위별 숫자 값을 비교해 정렬 순서 구현 |
| 사용자 입력의 안전한 출력 | innerHTML 대신 createElement와 textContent를 사용해 XSS 방지 |
| 모바일 화면과 다크모드 대응 | 미디어 쿼리와 CSS 변수를 사용해 375px 레이아웃 및 테마 구현 |

## 4. 미완성 항목

필수 요구사항은 모두 구현했으나 다음 도전 과제(선택)는 미완성했습니다.

| 도전 과제 | 미완성 내용 |
| --- | --- |
| 빈 화면 안내 | 목표가 없을 때 안내 문구와 예시 제안 |
| 애니메이션 | 항목 추가·삭제 시 부드러운 전환 |
